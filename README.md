# FIFO Prefix Inference

Private author archive for exact fixed-ledger FIFO parameter inference and timing
certificates. This repository contains research code, measured synthetic results
and reproduction instructions, not the manuscript or internal review material.

## Complete reproducibility package

Download FIFO_reproduction_v1.zip and extract it into a new directory. The ZIP is
self-contained: algorithms, test controls, locked inputs, raw measurements,
descriptive tables, finite verification evidence and the complete exact-check
transcript. Run the two commands in its README to verify the saved records.
The optional source/ tree mirrors code for convenient inspection; the ZIP remains
the complete data-and-code entry point with its own checksum manifest.

- Original comparison: 192 fixed inputs, three exact methods.
- Separate follow-up: 36 workflows, six repetitions, query-demand reversals kept.
- Exact evidence: full 302,369-line slice transcript and finite controls.
- DATA_DICTIONARY.md: field definitions, units and aggregation boundaries.
